PharmaSafe methodology

PharmaSafe is designed as a transparent research interface around public FDA adverse-event data. The application prioritizes reproducible queries, visible assumptions, and clear separation between statistical screening and clinical interpretation.

1. Data source

The core drug-event workflows query the openFDA drug adverse-event endpoint, which exposes public FAERS-derived records in JSON form. The source is FDA data; PharmaSafe does not create or simulate adverse-event reports.

2. Drug analysis

The drug-analysis workflow searches the public event index for a medicinal product and summarizes returned reaction terms and related fields. Counts shown in the interface are source-derived report counts. Where the source does not provide a value, PharmaSafe does not fabricate one.

3. Reaction search

The reaction-search workflow reverses the perspective: instead of starting with a drug, it searches for products reported alongside a reaction or MedDRA preferred term. This is useful for exploratory research, but the same multi-drug/multi-reaction limitation applies.

4. Signal detection

PharmaSafe builds the contingency information needed for ROR and PRR screening and displays 95% confidence intervals. The application describes these as statistical screening signals because the source is a spontaneous-reporting database and does not establish causality.

5. Trend and outcome views

Trend views organize report volume by receive date. Outcome views summarize coded outcomes in the returned reports. Neither should be interpreted as a population-level risk estimate without additional denominators and study design.

6. Term handling

Where raw text fields contain harmless formatting variation, PharmaSafe uses conservative normalization for display and aggregation. The application does not claim that raw free-text reporting is equivalent to a validated clinical classification.

7. User workspace

The authenticated dashboard stores a small user-scoped research collection and recent-analysis activity. Research Board items reference a drug name and summary metadata rather than copying the underlying FDA dataset. Access is intended to remain limited to the authenticated account.

8. Reproducibility and limitations

openFDA data are updated periodically and can lag the source reporting system. Query results can also change as the public dataset is revised. PharmaSafe therefore presents current returned data rather than treating a result as permanent truth.

What PharmaSafe does not claim

It does not diagnose adverse reactions, estimate true incidence from spontaneous reports, establish causality, or replace FDA labeling, clinical judgment, or formal safety assessment.

Primary references: openFDA Drug Adverse Event API and FDA AEMS.
